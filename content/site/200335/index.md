## 🎯 网站介绍

用友畅捷通好会计 是用友旗下专为小微企业打造的智能云财税服务平台。它深度融合了人工智能技术，旨在帮助创业者、财务人员及代账会计高效处理日常财税工作。平台以发票管理为核心切入点，通过OCR识别、智能凭证、自动计税和报表生成等功能，将传统繁琐的会计工作自动化、智能化，大幅提升工作效率并降低出错率，是中小企业实现财税数字化的得力助手。

## ✨ 核心功能

1. **智能发票管理**：支持多种发票的OCR扫描识别，自动提取关键信息并查验真伪。
2. **自动生成凭证**：根据发票和业务数据，利用AI技术自动生成会计凭证，减少手工录入。
3. **全税种申报**：一键测算税负，自动生成申报表，并支持对接电子税务局进行申报。
4. **多维度报表**：实时生成资产负债表、利润表等财务报表，辅助经营决策。
5. **移动端应用**：提供APP和微信端，方便随时随地进行查账、开票、审批等操作。

## 🚀 使用场景

1. **小微企业主**：缺乏专职会计，需要简单易用的工具自行管理公司账务和税务。
2. **代账会计/财税代账公司**：需要高效处理多家客户的海量票据，实现批量自动化做账与报税。
3. **企业财务人员**：希望从重复性的手工录入和核算工作中解放出来，转向更高价值的财务分析与管理。
4. **初创公司/自由职业者**：业务初期，需要以最低成本合规地完成基础的财务记账与税务申报。

## 📝 使用建议

1. **初期设置**：开通后，建议先根据企业性质（如小规模纳税人或一般纳税人）完成基础信息、科目和税种的初始化配置。
2. **养成习惯**：日常业务产生的发票和单据，建议随时通过手机APP拍照上传，避免月底集中处理，工作更轻松。
3. **善用自动化**：充分使用“智能凭证中心”和“期末结转”等自动化功能，它们能处理大部分常规业务，人工仅需审核和调整特殊事项。
4. **定期核对**：尽管系统自动化程度高，但仍建议每月或每季度核对银行流水、发票与系统记录，确保账实相符。
